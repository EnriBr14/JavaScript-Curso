# JavaScript Curso

Repositorio que contiene ejercicios, ejemplos y prácticas desarrolladas durante mi proceso de aprendizaje de **JavaScript**.

## 📚 Descripción

Este repositorio reúne diferentes ejercicios y ejemplos enfocados en el aprendizaje de JavaScript, desde conceptos básicos hasta prácticas más avanzadas.

El objetivo es reforzar habilidades de programación, comprender mejor la lógica de JavaScript y documentar mi progreso durante el curso.

## 🚀 Tecnologías utilizadas

- JavaScript
- HTML
- Programación orientada a objetos (POO)

## 📂 Contenido del repositorio

En este repositorio podrás encontrar ejercicios relacionados con:

- Variables y tipos de datos
- Operadores
- Condicionales (`if`, `switch`)
- Ciclos (`for`, `while`)
- Funciones
- Arreglos y objetos
- Manipulación del DOM
- Resolución de problemas con JavaScript

## 🎯 Objetivo del proyecto

- Practicar la sintaxis de **JavaScript**
- Desarrollar lógica de programación
- Comprender conceptos fundamentales del lenguaje
- Documentar el progreso durante el aprendizaje del curso

## ▶️ Cómo usar este repositorio

1. Clona el repositorio:

```bash
git clone https://github.com/EnriBr14/JavaScript-Curso
```

2. Abre la carpeta del proyecto.

3. Ejecuta los archivos `.js` en tu navegador o usando Node.js según corresponda.

## 🧠 Aprendizajes

Durante el desarrollo de estos ejercicios se practican habilidades como:

- Resolución de problemas
- Pensamiento lógico
- Buenas prácticas en JavaScript
- Organización de código
